2x scale (2560 x 1440), then resized to 1600 px wide and saved as WebP (quality 82, no metadata).

They show this repo's code at commit `d157dd9` (`main`) plus the signed-off demo change on
branch `portfolio/nov4`, running on a **local** server (`DEV_CDN=1`), not the live site. The
player name is "Josh"; everyone else is a bot. The room code in the lobby shot belonged to a local
room that no longer exists.
